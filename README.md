# 병기본 마스터 (PWA)

정신전력 백지암기 + 화생방 질의응답 병기본평가 대비 앱. 빌드 없는 정적 PWA.

- **화생방**: 플래시카드(스와이프 알아요/몰라요), 객관식 10문제, 모의 질의응답(평가관 질문 → 말로 답 → 자가채점), 오답노트, 정리본(MOPP·경보 표)
- **정신전력**: 읽기 → 첫 글자 암기 → 빈칸 Lv1(초성 힌트)·Lv2·Lv3 → 백지 쓰기(핵심키워드 70% + 문장 일치도 30% 자동 채점), 우리의 자세 메모
- 기록: 점수 히스토리, 최고점, 카드 암기 상태 (localStorage)

## 실행
```
python3 -m http.server 8000   # http://localhost:8000
```
GitHub Pages 등 HTTPS 정적 호스팅에 올리면 홈 화면에 설치 가능.

## 수정
- 문항: `js/data.js` (정신전력은 `{중괄호}` = 청색 핵심키워드)
- 아이콘: `icons/` 의 PNG 교체 (192, 512, maskable 512, apple-touch 180)
- 배포 후 `sw.js` 의 `VERSION` 올리기
